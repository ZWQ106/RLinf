## 已知 gotchas（按重要性）

### 1. zerorpc 关键字参数被吞 ★★★
DROID 这版 zerorpc client/server **kwargs 静默丢弃**，server 用默认值。

```python
# ❌ 错的 — action_space 被丢，server 用默认 cartesian_velocity → IK 解出错的 joint motion
c.update_command(action_8d, action_space="joint_velocity", blocking=True)

# ✓ 全用位置参数
c.update_command(action_8d, "joint_velocity", None, True)
```

`_droid_client.py` 已封装这个坑（`update_joint_velocity` / `update_joint_position` 内部用位置）。**任何绕过 wrapper 直接 `c._client.update_command(...)` 的地方都要用位置参数。**

### 2. FCI exclusivity ★★★
只能一个 libfranka client 同时连 FR3：旧 `franka-robot-server` (franky) **OR** 新 `droid-nuc-fr3` (polymetis)。同时起两个 → port 4242 冲突 + container 不停 crash。

### 3. Dashboard /status 显示 robot_ok=False ★
Cosmetic — 那个健康检查还在 HTTP probe `100.75.6.62:4242`（现在是 zerorpc port，HTTP timeout）。实际 droid_client 路径正常，eval 不受影响。**忽略**。

### 4. ZED Mini USB 反复掉线 ★
腕部 SN 17150101 在 `lsusb` 看得到，但 SDK `CAMERA NOT DETECTED`。物理接触不实。Desktop reboot / 振动后要 reseat。

### 5. ZED SDK neural model corrupt ★
后台 ZED open 时报 `CORRUPTED SDK INSTALLATION`（30% optimize 后 fail）。Dashboard 用 PERFORMANCE depth mode 不走 neural 所以 OK。要跑别的工具（calibration）才会撞。

### 6. Container 内 conda env 必须 source
所有 polymetis 进程在 `polymetis-local` conda env。`docker exec ... bash` 进去后要 `source /root/miniconda3/etc/profile.d/conda.sh && conda activate polymetis-local`。

### 7. parameters.py IP 跟 DROID 默认反 ★
DROID 默认 `nuc_ip=172.16.0.1, robot_ip=172.16.0.2`；**我们是 `nuc_ip=172.16.0.2, robot_ip=172.16.0.1`**。`~/polymetis_fr3/parameters.py` 已经改对了 + compose 挂进 container。重 build image 时要检查这点。

### 8. DROID FrankaRobot 是 lazy init
container 启动后 polymetis driver **不会自动起**。要 zerorpc client 调用 `c.launch_controller()` 触发 spawn（耗 ~5-10s），然后 `c.launch_robot()` 连 RobotInterface。
`DroidLikeClient.bootstrap()` 把这俩串起来，dashboard `start()` 和 `get_droid()` 都内部调。

### 9. update_command 默认 cartesian_velocity
DROID `FrankaRobot.update_command(command, action_space="cartesian_velocity", ...)` 默认 cartesian。pi05_droid 发的是 joint velocity，必须显式传 `"joint_velocity"`。`DroidLikeClient.update_joint_velocity` 已经封进去了。

### 10. action 8 维但 7 关节
DROID action 是 8-D：`action[:7]` = 7 joint velocity，`action[7]` = gripper command [0,1]，0=open，1=close。

## 关键概念速查

- **`droid-nuc-fr3:0.18.1`** = image，container name `droid-nuc-fr3`
- **`_droid_client.py`** = Desktop 侧 thin zerorpc wrapper，封 zerorpc kwargs trap + state list unwrap
- **bootstrap()** = `launch_controller()` + `launch_robot()` 合二为一（lazy，第一次 ~10s）
- **DROID action space**: `"joint_velocity"` for pi05_droid（不是默认的 `"cartesian_velocity"`）
- **DROID gripper convention**: state.gripper_position ∈ [0,1] 1=close；action[7] ∈ [0,1] 0=open 1=close
- **DROID home pose**: `[0, -π/5, 0, -4π/5, 0, 3π/5, 0]`
- **`max_joint_delta = 0.2`** rad/step，control rate 15 Hz
